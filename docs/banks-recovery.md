# Проверка банковских ML-источников

Дата адресной проверки: 5 октября 2026. Запросы были ограничены публичными career-страницами, API и несколькими адресными HH RSS/detail страницами. Полная сборка приложения здесь не запускалась.

## Альфа-Банк

- Публичный API `https://job.alfabank.ru/api/vacancies?businessLine=1018&take=100&skip=0` отвечает HTTP 200, `total=25`, возвращает `items[]`, `descriptionText`, `requirements`, `experienceId`, `expirationDate` и `slug`. Значение 1018 пригодно как IT/business-line фильтр, но это не младшая выборка: текущая выдача включает `Старший ML инженер`, `Senior data scientist`, `Team lead data science`, `Middle data scientist` и другие более опытные роли.
- У карточек `isHidden:false`, явного `isActive` в проверенных элементах нет. Адаптер определяет доступность по `expirationDate` и скрытости, а грейд берёт только из названия, не приписывая значение непрозрачному `experienceId`.
- Проверенные публичные ссылки: [Старший ML инженер](https://job.alfabank.ru/vacancies/moskva/remote-job/starshii-ml-inzhener_38826) HTTP 200; [Data Scientist, Antifraud](https://job.alfabank.ru/vacancies/moskva/remote-job/data-scientist-%28platforma-ogranichenii-antifraud%29_37964) HTTP 200. Первая явно senior и должна быть исключена фильтром intern/junior.
- [iChooseAlfa](https://alfabank.ru/alfafuture/ichoosealfa/) в этой среде ответил HTTP 403. Не обходить. Источник оставляет статус программы неподтверждённым при таком ответе.

## Т-Банк

- [Пользовательская страница каталога](https://www.tbank.ru/career/vacancies/all/moscow/?profession=ml) вернула шаблон ошибки `500 | Т-Банк` при HTTP 200 внешнего ответа. В `pfpjobs/papi/getVacancies` проверен один запрос без фильтров (`category=it`) и значения профессии `ml`, `ML`, `machine_learning`, `data_scientist`, `ml_engineer`; каждый ответ содержал `resultCode=OK`, но 0 вакансий. Поле `nextPagination.it` для запроса без фильтра подтверждало `totalCount=0`, `isFinished=true`. Ни профессия, ни фактические ссылки карточек по этому API не подтверждены.
- Не задавать guessed `tbank.professions`: для прямого каталога остаётся блокер актуального протокола. HH — рабочий проверенный резерв.
- [Т-Банк ML internship](https://education.tbank.ru/start/ml_engineer/) отвечает HTTP 200 и описывает оплачиваемую стажировку для начинающих специалистов, от 20 часов в неделю, с ML-задачами. Сейчас на странице CTA «Подписаться на анонсы», а текст не подтверждает открытый набор. Адаптер возвращает health `unknown` и не создаёт карточку. Если страница явно сообщит, что приём открыт, адаптер создаёт карточку с `opportunityType: internship_program`, `availability: active`, `level: intern`.
- [Одна карточка HH](https://hh.ru/vacancy/137379291) открывается HTTP 200 и содержит JobPosting JSON-LD; заголовок ML-инженер, категория опыта 3–6 лет. Требования не содержат обязательного числового минимума, но агрегатная категория 3–6 не подходит как junior автоматически.

## HH: адресная проверка работодателей

Для каждого названия сделан один RSS-запрос `NAME:ML AND COMPANY_NAME:"…"`; это быстрый proof пути, не исчерпывающий поиск. RSS ограничивает выдачу 20 элементами.

| Искомый работодатель | Найдено в одном запросе | Точные company strings из карточек |
|---|---:|---|
| Сбер | 20 (лимит RSS) | `Сбер. Data Science`, `Сбер. IT`, `Страховая компания Сбербанк страхование` |
| Т-Банк | 8 | `Т-Банк. ИТ. Разработка` |
| Альфа-Банк | 3 | `Альфа-Банк. Центральный офис` |
| Райффайзенбанк | 0 | алиасы `Райффайзен`, `Райффайзен Банк`, `Raiffeisen`, `Raiffeisenbank` тоже дали 0 |
| VK | 4 | `VK, AI VK` |
| Яндекс | 8 | `Яндекс`, `Яндекс Еда`, а также названия подразделений/сервисов; нужны только явно проверенные алиасы |
| Авито | 0 | `Авито`, `Avito`, `AvitoTech` дали 0 |
| Ozon | 11 | `Ozon Tech` |
| Wildberries | 1 | `RWB (Wildberries & Russ)` |

Публичные карточки Сбера и Т-Банка отдают JSON-LD `JobPosting`. [Сбер Junior/Middle Data Scientist](https://hh.ru/vacancy/136811152) сообщает агрегатную категорию `3–6 лет`, но в требованиях сказано «от 1 года в ML» и допускаются сильные кандидаты с меньшим опытом и pet-проектами. Противоречие должно идти на ручную проверку, не считаться junior автоматически. Карточка также отдаёт формат, обязанности и полный текст требований.

`hh_targets` сверяет работодателя точным нормализованным совпадением по alias и помечает `targetEmployer`. Для карточек загружается ограниченное число detail страниц HH (по умолчанию до 80, только `https://hh.ru/vacancy/<id>`), чтобы передать JSON-LD description, требования и категорию опыта. Ошибки/отсутствие JSON-LD сохраняются в health; RSS остаётся доступным источником даже при частичных ошибках detail.

## Дальнейшая настройка

Для `hh.employers[].aliases` использовать только строки, реально увиденные в поле компании HH. Подтверждённые значения: `Сбер. Data Science`, `Сбер. IT`, `Т-Банк. ИТ. Разработка`, `Альфа-Банк. Центральный офис`, `VK, AI VK`, `Яндекс`, `Яндекс Еда`, `Ozon Tech`, `RWB (Wildberries & Russ)`. Райффайзен и Авито остаются без live ML-RSS совпадений на дату проверки.

Для `tbank.professions` не выставлять значение до появления непустого результата с валидной карточкой и ссылкой. Для прямой страницы и endpoint не отключать TLS и не обходить защиту.
