Локальный агент, который ищет тебе работу — сам, каждые 6 часов, пока ты занят делом.

$ git clone …/sasaki-agent && npm run setup

Нужен только Node.js 21+. Или просто попроси агента поставить.

Лента находок127.0.0.1:4321

Один агент вместо десятка вкладок с досками вакансий.

Ставится за три команды и дальше работает в фоне. Тебе остаётся выбирать и откликаться.

Обходит источники сам

19 источников из коробки — hh, LinkedIn, getmatch, Хабр Карьера, карьерные сайты компаний и телеграм-каналы. Раз в 6 часов, без твоего участия.

Отбирает по критериям

Направление, уровень, формат работы. Дубли между источниками отсеивает, показанное не повторяет — в ленте только новое и подходящее.

Ведёт твои отклики

Воронка Новый → Отклик → Собес → Тестовое → Оффер, рядом — сопроводительное письмо. Ненужное скрываешь одной кнопкой.

Три команды — и пульт открыт.

Установка неинтерактивная: ставит автозапуск, поднимает пульт и сама открывает его в браузере.

Руками

В терминале, по порядку:

$ git clone https://github.com/peachcardinal/sasaki-agent.git $ cd sasaki-agent $ npm run setup

Нужен только Node.js 21+ — проверить: node -v

Или попроси агента
