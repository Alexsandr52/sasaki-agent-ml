01 / что умеет

Один агент вместо десятка вкладок с досками вакансий.

01

Обходит источники сам

19 источников из коробки: hh, LinkedIn, getmatch, Хабр Карьера, карьерные сайты компаний и публичные телеграм-каналы. Раз в 6 часов, в фоне, без твоего участия.

каждые 6 часов
02

Всё остаётся у тебя

Критерии, найденные вакансии, статусы откликов и черновики писем лежат на твоём компьютере. Никакого облака, аккаунтов и телеметрии — наружу не уходит ничего.

локально и приватно
03

Ведёт твои отклики

Переносишь вакансию в «Отклики» и ведёшь воронку: Новый → Отклик → Собес → Тестовое → Оффер. Рядом — сопроводительное письмо. Ненужное скрываешь одной кнопкой.

трекер откликов
04

Учится новым сайтам

Список источников не зафиксирован. Понравился сайт, которого нет в списке — говоришь агенту одну команду, и он сам пишет к нему адаптер и подключает.

/add-source
02 / без магии

Чего не умеет

  • Не откликается за тебя. Собирает и раскладывает — решаешь и пишешь ты.
  • Не оценивает релевантность умнее ключевых слов. Фильтр по названию, грейду и формату; иногда мусор пролезает.
  • Не лезет в закрытое. Только то, что доступно публично — без логинов и риска бана.
  • Не заменяет нетворк. Часть хороших вакансий всё равно приходит не с досок.

04 / установка

Три команды — и пульт открыт.

bash
$ git clone https://github.com/peachcardinal/sasaki-agent.git
$ cd sasaki-agent
$ npm run setup
 
# ставит автозапуск, поднимает пульт
# и сам открывает 127.0.0.1:4321

Или попроси агента

Есть Claude Code или другой кодовый агент? Открой его в пустой папке и скажи:

// вставь как есть Установи мне агента из github.com/peachcardinal/sasaki-agent — склонируй, запусти установку и расскажи, как пользоваться

Установка неинтерактивная — вопросов агенту не задают, он не застрянет. Нужен только Node.js 21+ (проверить: node -v). Дальше в пульте отметь направление и уровень и жми «Найти вакансии».

05 / чем отличается от агрегаторов

Увидел вакансию на сайте, которого нет в списке? Добавь его.

Готовый агрегатор живёт своим списком источников, и ты в нём заперт. У sasaki список открытый: открываешь папку проекта в агенте и говоришь одну команду — он сам разберётся, как сайт отдаёт данные, напишет адаптер, проверит на живых вакансиях и подключит. Новый источник появится в пульте сам.
