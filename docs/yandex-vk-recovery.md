# Проверка источников Яндекса и VK

Проверено 2026-10-05 на публичных страницах/API без cookies и без запуска общего collector.

## Яндекс

- Каталог вакансий: `https://yandex.ru/jobs/api/publications` отвечает HTTP 200 и отдаёт курсорную выдачу.
- Публичные фильтры подтверждены страницей каталога и запросами: `ml-developer` (71 запись) и `analyst-developer` (79 записей). Совместный запрос вернул 150 записей. `data-analyst` возвращает 0 и не является подходящим profession slug.
- Детальная карточка `https://yandex.ru/jobs/api/publications/49090` отвечает HTTP 200 и содержит `vacancy.pro_level_min_display/max_display`, `description`, `key_qualifications`, `additional_requirements`, `published_at`.
- Основной адаптер использует `page_size=20`, до 20 страниц и дедупликацию ID. Детали запрашиваются не более чем для 100 записей за прогон; приоритет у ML/DS, затем стажировок/junior, порядок API сохраняется внутри приоритета. Ошибка одной карточки не удаляет запись из каталога; пропуск или ошибка деталей отражается в `sourceMeta`, а дата остаётся пустой. Значения `published` кэшируются только для успешно прочитанных detail-записей.
- Рекомендуемая настройка: `yandex.professions: ["ml-developer", "analyst-developer"]`. Второй фильтр широкий и включает продуктовую/бизнес-аналитику; центральный фильтр должен отсекать нерелевантные названия.
- Прямая страница вакансии строится как `https://yandex.ru/jobs/vacancies/<publication_slug_url>`.

## Яндекс ML-стажировка

- Официальная [страница программы](https://yandex.ru/yaintern/ml) отвечает HTTP 200, заголовок подтверждает ML-стажировку.
- FAQ прямо говорит: «Стажировка проходит круглый год, поэтому вы можете подать заявку в любое время». Адаптер возвращает одну запись `opportunityType: "internship_program"`, `availability: "active"`, `level: "intern"`. Минимальный опыт не указан, поэтому `experienceMin` не выставляется.
- Если страница перестанет одновременно подтверждать ML-направление и открытый набор, адаптер возвращает пустой список и `sourceMeta.status: "unknown"`, без выдачи программы как доступной возможности.

## VK

- Справочник каталога подтверждает `specialty=283` для Machine Learning и `specialty=281` для Data Science. Это рекомендуемые `vk.specialties`.
- Live запуск адаптера для `specialty=283` вернул 13 карточек и успешно загрузил 13 деталей; лимит страниц не достигнут.
- Целевая карточка [ML-инженер, ID 54687](https://team.vk.company/vacancy/54687/) отвечает HTTP 200. Официальные метаданные указывают «уровня senior»; раздел требований содержит «Опыт в ML от двух лет». Адаптер включает требования в запись и устанавливает `level: "senior"`, так что карточка не помечается как junior.
- Детали карточек дополняют SSR-каталог. Ошибка отдельной страницы сохраняет запись списка и помечает source metadata как partial.
- `targetEmployer: "ВК"` задаётся отдельно от `company: "VK · ..."`, чтобы объединённый отчёт группировал все подразделения вместе.
